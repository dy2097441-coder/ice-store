How to install

  1. Click Download under an app. A message says it was saved in Home/Downloads.
  2. Open Files and go to Home, then Downloads.
  3. Double-click the .app file to run it. Press Esc to close it.

Make your own

An app is a plain text file ending in .app. The first line must be ICEBERG-APP 2. This one counts button clicks:

ICEBERG-APP 2
title Counter
size 200 130
var n 0
text 20 20 Count: {n}
button 20 50 80 30 add Add 1
on add
set n n + 1
end
  • title - the window title
  • size - total window width and height
  • var name number - a whole-number variable
  • text x y words - writes words; {n} shows a value
  • rect x y w h r g b - a filled box (colours 0 to 255)
  • display x y w h expression - a number box
  • button x y w h handler label - a button; use handler:5 to pass the number 5 as arg
  • key c handler - a keyboard key (or enter, backspace) runs a handler
  • on name ... end - a handler. Inside: set name expression, if expression / else / endif, call name

Expressions use whole numbers, variables, ( ) + - * / % and comparisons like == != < > && ||. A mistake shows a red message at the bottom of the app window.
