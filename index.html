How to install

  1. Click Download under an app. A message says it was saved in Home/Downloads.
  2. Open Files and go to Home, then Downloads.
  3. Double-click the .app file to run it. Press Esc to close it.

Make your own

An app is a plain text file ending in .app. The first line must be ICEBERG-APP 1. Example:

ICEBERG-APP 1
title Hello
size 260 110
text 20 30 Hi there
rect 20 60 80 20 40 80 200
  • title - the window title
  • size - window width and height
  • text x y words - writes words at that spot
  • rect x y w h r g b - a filled box with a colour (0 to 255 each)
